# JWT（JSON Web Token）デコーダー＆クレーム検証ツール

JWTトークンをヘッダー・ペイロード・署名に分解してJSON整形表示する。iat/exp/nbfを日本語で日時変換し、有効期限の残り時間を色付き表示（期限切れは赤）。RS256/ES256トークンはPEM公開鍵を入力することでWeb Crypto APIによる署名検証が可能。HS256・RS256・有効期限未来のサンプルJWT付き。

## 使い方

テキストエリアにJWTトークンを貼り付けて「デコードする」ボタンを押す。RS256/ES256の場合は公開鍵欄にPEM鍵を入力し「署名を検証する」をクリック。サンプルボタンで動作確認可能。
